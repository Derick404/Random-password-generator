#  Random Password Generator

A simple JavaScript app that generates secure, random passwords with options for letters, numbers, and symbols.

## Features
- Generate strong random passwords  
- Copy to clipboard with one click  
- Customizable length and character sets  

## Setup
1. Clone or download this repo  
2. Open `ind.html` in your browser  

##  Usage
Click **Generate** to create a password, then hit **Copy** to copy it to your clipboard.
